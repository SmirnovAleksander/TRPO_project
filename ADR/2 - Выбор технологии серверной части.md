# ADR: Выбор технологии серверной части

**Контекст:**  
Серверная часть должна обрабатывать финансовые операции, права доступа, бюджеты, сберегательные цели, отчеты и многопользовательскую работу. Требуются удобная работа с API, базой данных и бизнес-логикой.

**Рассмотренные варианты:**  
- Python + FastAPI
- C# + ASP.NET Core
- Node.js + NestJS

**Решение:**  
Использовать Python и FastAPI.

**Обоснование:**  
FastAPI позволяет быстро создавать REST API, поддерживает асинхронную обработку запросов, автоматическую генерацию документации OpenAPI и удобную валидацию данных. Python хорошо подходит для учебного проекта благодаря простоте разработки и большому количеству библиотек.

**Последствия:**  
Серверная часть будет разрабатываться на Python с использованием FastAPI. Для работы с базой данных потребуется отдельный ORM или SQL-библиотека, а структура проекта должна четко разделять API, бизнес-логику и доступ к данным.
