# ADR: Выбор инструментов автоматического тестирования

**Контекст:**  
Система содержит финансовую бизнес-логику, права доступа и операции с базой данных. Ошибки в этих частях могут приводить к неправильным расчетам или потере целостности данных.

**Рассмотренные варианты:**  
- Только ручное тестирование
- unittest
- pytest
- pytest + TestClient

**Решение:**  
Использовать pytest и TestClient FastAPI.

**Обоснование:**  
pytest позволяет удобно создавать модульные и интеграционные тесты, а TestClient используется для проверки API без запуска отдельного сервера. Такой набор хорошо подходит для приложений на FastAPI.

**Последствия:**  
Критическая бизнес-логика и основные API должны покрываться автоматическими тестами. Для тестирования базы данных потребуется отдельная тестовая конфигурация.
