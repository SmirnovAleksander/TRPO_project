# ADR: Выбор технологии клиентской части

**Контекст:**  
Пользовательский интерфейс должен работать на компьютерах и мобильных устройствах, быть понятным и обеспечивать быстрый доступ к основным финансовым функциям.

**Рассмотренные варианты:**  
- React + TypeScript
- Vue + TypeScript
- Angular

**Решение:**  
Использовать React и TypeScript.

**Обоснование:**  
React подходит для создания интерактивных веб-интерфейсов, а TypeScript снижает количество ошибок за счет статической типизации. Решение позволяет реализовать адаптивный интерфейс для разных размеров экрана.

**Последствия:**  
Клиентская часть будет разрабатываться как веб-приложение. Интерфейс необходимо проектировать адаптивным и поддерживать единые компоненты для основных экранов системы.
