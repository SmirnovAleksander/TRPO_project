# ADR: Выбор технологического процесса разработки

**Контекст:**  
Проект разрабатывается командой, поэтому требуется единый процесс работы с исходным кодом, ветками и изменениями. Необходимо выбрать Git-платформу, которая упростит совместную разработку и хранение архитектурной документации.

**Рассмотренные варианты:**  
- GitHub
- SourceCraft
- GitLab

**Решение:**  
Использовать GitHub.

**Обоснование:**  
GitHub предоставляет Git-репозитории, Pull Request, Issues и удобные средства совместной работы. Платформа широко используется, имеет большое количество интеграций и подходит для учебного проекта.

**Последствия:**  
Исходный код и архитектурная документация будут храниться в GitHub. Новые изменения будут разрабатываться в отдельных ветках и добавляться в основную ветку после проверки через Pull Request.
