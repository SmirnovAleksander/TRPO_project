# ADR: Выбор архитектурной формы системы

**Контекст:**  
Система семейного бюджета включает управление пользователями, доходами, расходами, категориями, бюджетами, сберегательными целями, детским бюджетом, аналитикой, уведомлениями и данными. Необходимо разделить ответственность между частями системы, сохранив простоту разработки и сопровождения.

**Рассмотренные варианты:**  
- Монолит
- Модульный монолит
- Микросервисная архитектура

**Решение:**  
Использовать модульный монолит.

**Обоснование:**  
Модульный монолит позволяет разделить систему на независимые логические модули без сложности микросервисной архитектуры. 
Такой подход подходит для текущего масштаба проекта и упрощает разработку, тестирование и развертывание.

**Последствия:**  
Система будет разрабатываться как единое приложение с отдельными модулями. Необходимо контролировать зависимости между модулями и не смешивать их ответственность.
