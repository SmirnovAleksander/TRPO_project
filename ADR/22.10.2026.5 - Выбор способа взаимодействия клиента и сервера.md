# ADR: Выбор способа взаимодействия клиента и сервера

**Дата:** 22 октября 2026 г.

**Статус:** Принято

**Команда:**
- Соловьев Александр
- Барыльник Владимир
- Смирнов Александр

**Контекст:**  
Клиентское приложение должно получать и изменять данные о пользователях, операциях, бюджетах, целях и отчетах через серверную часть. Требуется простой и распространенный способ взаимодействия.

**Рассмотренные варианты:**  
- REST API
- GraphQL
- RPC

**Решение:**  
Использовать REST API с передачей данных в формате JSON.

**Обоснование:**  
REST прост в реализации и подходит для CRUD-операций, составляющих значительную часть системы. JSON удобно использовать совместно с React и Spring Boot.

**Последствия:**  
Серверная часть должна предоставлять документированный набор HTTP-эндпоинтов. Необходимо соблюдать единые правила именования ресурсов, обработки ошибок и формата ответов.
