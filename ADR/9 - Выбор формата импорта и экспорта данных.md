# ADR: Выбор формата импорта и экспорта данных

**Контекст:**  
Система должна позволять пользователям импортировать и экспортировать финансовые данные. Формат должен быть распространенным, простым для обработки и доступным пользователю вне приложения.

**Рассмотренные варианты:**  
- CSV
- JSON
- XLSX

**Решение:**  
Использовать CSV как основной пользовательский формат импорта и экспорта.

**Обоснование:**  
CSV поддерживается большинством табличных редакторов, имеет простую структуру и подходит для представления списка финансовых операций. Формат не требует специальных библиотек для просмотра пользователем.

**Последствия:**  
Необходимо определить единый набор колонок, формат дат, чисел и кодировку файлов. При импорте система должна проверять структуру и корректность входных данных.
