# ADR: Выбор системы хранения данных

**Контекст:**  
Система хранит пользователей, семьи, финансовые операции, категории, бюджеты, сберегательные цели и права доступа. Между этими данными существуют четкие связи, а для финансовых операций важны целостность и надежность.

**Рассмотренные варианты:**  
- PostgreSQL
- MySQL
- MongoDB

**Решение:**  
Использовать PostgreSQL.

**Обоснование:**  
PostgreSQL поддерживает транзакции, ограничения целостности, связи между сущностями и сложные запросы. Это соответствует требованиям финансовой системы, где важно предотвращать потерю и противоречивость данных.

**Последствия:**  
Основные данные будут храниться в реляционной базе PostgreSQL. Изменения структуры данных необходимо выполнять через контролируемые миграции.
